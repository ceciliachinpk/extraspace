EXTRA SPACE ASIA - PERSONAL STORAGE APP
Interactive prototype (no video, no install)


HOW TO OPEN

  1. Unzip this folder anywhere - the Desktop is fine.
  2. Double-click  index.html

  It opens in any browser. Nothing to install and nothing to sign into.


WHAT YOU CAN DO

  Everything is clickable. Pins, cards, filter chips, forms and the bottom
  tab bar all respond.

  The list on the launcher page jumps straight to any screen in the journey,
  so you can go to the part you want to talk about instead of clicking
  through to reach it.

  Sign-in accepts any mobile number and any 6-digit code.

  "Start from the splash screen" puts it back to a cold start, signed out -
  useful before you hand the laptop to someone else.


GOOD TO KNOW

  It works with no internet connection at all. The map is drawn from
  coastline data inside the folder rather than fetched from a map service,
  so nothing here depends on a server being reachable.

  It is built for a phone screen (iPhone 17, 402 x 874). On a laptop it is
  shown inside a phone frame, which is why there is space either side.

  Prices, invoices, branch details and reviews are realistic placeholders
  for review purposes, not live data.
